# Library Management System

## Project Description

This project is a simple Python program created to manage a small library. The user can add books, list all stored books, search for a book by title or author, and exit the program.

The project uses object-oriented programming and modular design by separating the Book class from the main program.

## Project Files

-`book.py`: Contains the Book class and stores the title, author, and ISBN of each book.
-`library_manager.py`: Imports the Book class and contains the functions and menu used to manage the library.
-`README.md`: Explains the project and how to run it.

## Program Features

1. Add a new book.
2. List all books.
3. Find a book by title or author.
4. Exit the program.

## How to Run the Program

1. Make sure Python is installed.
2. Keep `book.py` and `library_manager.py` in the same folder.
3. Open the terminal in the project folder.
4. Run this command:
```
python library_manager.py
```

5. Choose an option from the menu and follow the instructions.
